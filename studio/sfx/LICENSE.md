# MotionMind starter SFX pack — CC0 1.0

Every sound here is dedicated to the public domain (CC0 1.0, https://creativecommons.org/publicdomain/zero/1.0/):
free for personal and commercial videos, no attribution required. `catalog.json` records the source of each file.

| Folder | Source |
|---|---|
| `Clicks/`, `Pops/`, `Alerts/`, `Glitch/`, `Chimes/` success · glass · bong | **Kenney — Interface Sounds 1.0** (www.kenney.nl), CC0, renamed. Thank you, Kenney. |
| `Whooshes/`, `Risers/`, `Impacts/`, `Chimes/sparkle` | Synthesised by MotionMind (seeded filtered noise and sine sweeps), released as CC0 |

To use your own library instead, point `MOTIONMIND_SFX` at a folder with one sub-folder per category and run
`motionmind sfx scan`.
