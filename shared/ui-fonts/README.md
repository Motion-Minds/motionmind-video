# UI fonts (optional)

MotionMind Studio and the dashboard use these files when present and fall back to system fonts otherwise.
They are not shipped with the repo; download them from the original publishers under their licences:

| File | Font | Source |
|---|---|---|
| `Satoshi-Regular.otf`, `Satoshi-Medium.otf`, `Satoshi-Bold.otf`, `Satoshi-Black.otf` | Satoshi | https://www.fontshare.com/fonts/satoshi |
| `Geist-600.ttf` | Geist SemiBold | https://vercel.com/font (SIL Open Font License) |
